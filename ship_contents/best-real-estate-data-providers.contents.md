## FAQ

**1. 부동산 데이터 공급자가 뭔가요?**

부동산 데이터 공급자는 매물, 소유권 기록, 평가, 임대, 등기, 모기지, 동네 컨텍스트, 소유주 연락처 같은 부동산 관련 정보를 수집·통합해서, 대시보드·내보내기·API로 접근할 수 있게 만들어 주는 회사예요.

**2. 기록 기반 공급자와 실시간 웹 데이터 공급자의 차이는요?**

기록 기반 공급자는 공공 기록, 필지 파일, 등기 이력, 모기지 데이터 같은 구조화된 소스에 집중해요. 실시간 웹 데이터 공급자는 웹사이트에서 직접 가져옵니다. DB로 정규화되기 전에 가장 신선한 신호가 온라인에 먼저 뜨는 경우에 강해요.

**3. 비기술 부동산 팀에는 어떤 공급자가 좋아요?**

[Thunderbit](https://thunderbit.com/)이 맞춤 실시간 데이터가 필요한 비기술 팀에 가장 진입장벽 낮은 옵션이에요. [PropertyRadar](https://www.propertyradar.com/)는 작은 팀이 평가하기 가장 쉬운 미국 소유주 데이터 플랫폼 중 하나고요—명확한 플랜 티어를 공개하거든요.

**4. 부동산 제품을 만드는 개발자에게는요?**

미국 주거용 API 워크플로라면 [RentCast](https://rentcast.io/), [Realie](https://www.realie.ai/), [ATTOM](https://www.attomdata.com/)이 가장 명확한 후보예요. 저마찰 테스트, 공공 기록 깊이, 엔터프라이즈급 폭 중 어떤 걸 우선할지에 따라 답이 갈려요.

**5. 한 공급자만 써야 할까요, 여러 개를 조합할까요?**

대부분의 경우 여러 개를 조합해요. 많은 팀이 기초로 구조화된 기록 공급자 하나를 쓰고, 더 빠른 시장 신호·니치 소스·맞춤 수집용으로 실시간 웹 데이터 워크플로 하나를 함께 운영합니다.
